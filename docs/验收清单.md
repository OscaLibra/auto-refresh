执行环境：Chrome 120+ 与 Edge 最新稳定版**各跑一遍**。「结果」列填 `通过`，或写实际现象。

## 二、已由自动化覆盖的部分

以下项不需要手工重复验证，跑 `node tools/simulate*.mjs` 即可（共 90 项断言）：

- 装配顺序、双实例守卫、未命中零注入（TC-06 的注入面）
- 空闲判决到点刷新、30 秒防抖（TC-01 的判定面）
- 有操作重置计时（TC-02 / TC-03 的判定面）
- 提示浮层与「稍后」（TC-11 / TC-12）
- ping 模式发 HEAD 而非刷新（TC-15 / TC-16 的执行面）
- iframe 活动归并到标签（TC-17）
- 休眠唤醒宽限、系统时间回拨（TC-18）
- 暂停 / 恢复指令链路（TC-19）
- 动态注册幂等、权限撤销后标记、重新授权后恢复（TC-21 / TC-22）
- 兜底巡检阈值、加载中跳过、discard 救活、标签关闭清理

**仍需人工在真实浏览器验证的**：TC-04（降频行为依赖真实 Chrome）、TC-13（滚动恢复依赖真实排版）、TC-14（`beforeunload` 依赖真实用户手势）、TC-23（SPA 依赖真实站点）、TC-24（长时稳定性）。
